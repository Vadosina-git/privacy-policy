# privacy-policy — Codex

Статический сайт GitHub Pages с privacy/support страницами приложений флота.

Перед работой прочитай `~/.claude/CLAUDE.md` (единый источник общих предпочтений), затем `CLAUDE.md` этого проекта целиком. Это сохраненный источник предметных правил и обязательных триггеров документации; он применяется и к Codex. Не копируй глобальные предпочтения.

- `docs/CODEX.md` — порядок работы, инструменты и локальные процедуры.
- `docs/CODEX_ARCHITECTURE.md` — карта текущих файлов и границ.
- Профильные источники: CLAUDE.md. Читай по теме задачи до изменения.

Новому приложению нужны privacy и support страницы. Схему имен SKU сохранять; переименование URL требует проверки ссылок потребителей в разрешенном scope. Push main публикует сайт: миграция его не разрешает. Не добавлять framework/server ради документации.

Ищи только в этой папке, исключая зависимости, сборки, архивы и тяжелые референсы. Вложенный AGENTS.md/CLAUDE.md уточняет правила своей подпапки. Не правь исходники Claude ради совместимости с Codex. Коммиты, внешние отправки, деплой, публикация и новые зависимости требуют соответствующего поручения; эта миграция его не дает.
