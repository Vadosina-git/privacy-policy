# privacy-policy — карта для Codex

Проверено по существующим файлам 31.10.2026. Карта дополняет предметную архитектуру, а не заменяет ее.

HTML в корне публикуется как статические страницы; пары <app>-privacy.html/<app>-support.html привязаны к URL карточек сторов. Сервера приложения здесь нет.

| Путь от корня проекта | Назначение |
|---|---|
| `index.html` | главная страница статического сайта |
| `contact.html` | публичная страница контактов |
| `manage-data.html` | страница управления пользовательскими данными |
| `app-ads.txt` | публичная декларация рекламных продавцов |
| `subscription-terms/index.html` | статические условия подписки |
| `plinko-privacy.html` | пример privacy страницы конкретного SKU |
| `plinko-support.html` | пример support страницы конкретного SKU |

Перед изменением: CLAUDE.md при наличии, иначе [предметный справочник](CODEX_PROJECT_REFERENCE.md). Версии и зависимости сверяй с локальными manifest/lockfile, не обновляй стек вслед за сменой помощника. Архивы и соседние проекты не становятся рабочей областью по ссылке.
