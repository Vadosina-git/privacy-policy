# privacy-policy — предметные правила для Codex

Переносимый справочник по локальному CLAUDE.md. Читай его обязательно, если CLAUDE.md отсутствует в клоне. Исходный Claude-файл не изменялся.

Статический сайт GitHub Pages хранит публичные privacy policy и support-страницы приложений флота: по паре `<app>-privacy.html` и `<app>-support.html` на приложение. В корне также находятся `app-ads.txt`, `contact.html`, `manage-data.html` и каталог `subscription-terms`. Сервера приложения и отдельного framework здесь нет. Карта файлов: [CODEX_ARCHITECTURE.md](CODEX_ARCHITECTURE.md).

1. Для нового приложения нужны две страницы: privacy и support, а ссылки на них указываются в листинге стора. Рабочий privacy URL требуется App Store и Google Play.
2. Имя файла повторяет SKU: например `boxmaster-privacy.html` или `crush7-support.html`. Сохраняй существующую схему имен.
3. GitHub Pages отдает страницы из репозитория после push в main. Это публикация сайта и требует отдельного прямого поручения. Миграционные документы публикуются в отдельной ветке, без изменения main.
4. Ссылки потребителей находятся в документации приложений, в том числе их CLAUDE.md. При разрешенном переименовании страницы проверь и исправь ссылки в порученной области. Ссылка на соседний проект не дает права читать или менять его без соответствующего поручения.

Имена файлов сайта указаны от корня проекта. Правила инструментов, проверки и границ: [CODEX.md](CODEX.md).
